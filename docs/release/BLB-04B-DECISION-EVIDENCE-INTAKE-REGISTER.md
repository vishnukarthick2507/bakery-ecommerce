## 1. Purpose

Controlled register for receiving and auditing genuine owner/client decision responses. This register does not confirm decisions without evidence and does not authorize execution.

## 2. Intake rules

- Accept only: **Approve / Reject / Defer / Request clarification / Conditional approval**.
- Required for actual response: decision ID, selected option/response, approver name, approver role, confirmation date, conditions/limitations, supporting evidence reference.
- **No decision may be marked CONFIRMED** without genuine written evidence.
- **No execution authorization may be granted** by this register. Separate execution authorization is required for any operational activity.
- Silence, verbal assumptions, agent recommendations, or incomplete responses = **NOT RECEIVED / NOT CONFIRMED**.
